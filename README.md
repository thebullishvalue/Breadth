🌊 Market Breadth - Advance/Decline IntelligenceQuantitative Breadth + Trend System A Hemrek Capital ProductVersion: 1.5.0 (Nirnay Sync Engine)📌 OverviewMarket Breadth is an institutional-grade Streamlit application designed for rapid, vectorized analysis of market internals. By evaluating the performance of the NIFTY 500 (representing ~92% of free-float market cap on the NSE), it provides a clear, quantitative snapshot of underlying market health, stripping away index-weighting distortions.✨ Key FeaturesUltra-Fast Vectorized Engine: Replaces traditional sequential processing with Pandas matrix vectorization, evaluating 500 equities simultaneously across custom timeframes in milliseconds.Relative Breadth Oscillator: Utilizes a proprietary Fibonacci Sequence Moving Average (2D, 3D, 5D, 8D, 13D, 21D) smoothing technique to detect hidden overbought/oversold market states.Custom Breadth Oscillator: Features EMA-smoothed signal processing with a bi-color gradient visualizer (Green = Oversold Bias / Red = Overbought Bias).Cumulative A/D Line (ADL): Tracks the summation of net advancing stocks to map true underlying momentum and identify critical index divergences.A/D Ratio (ADR): Raw Advance/Decline ratio to instantly gauge daily market skew.Intelligent Data Fetching: Implements multi-tier fail-safes via NSE APIs and Wikipedia backups, with multithreaded yfinance pooling.⚙️ Installation1.
